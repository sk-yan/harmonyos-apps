# 一笔记账 1.1：审阅后的改进

本次预发布为 `1.1.0-preview.2`，原生版本 `1.1.0`、版本码 `1001001`。目标是把历史支付账单安全地带入本地账本，并让截图成为可核对的录入起点。三个独立审阅方向分别检查账务含义、日常操作和平台边界；以下记录实际修改与验证范围。

## 审阅结论与修改

| 审阅方向 | 具体问题与触发场景 | 本次修改 | 当前证据与边界 |
| --- | --- | --- | --- |
| 账务与导入 | 退款、转账、充值、还款直接按收入或支出导入，会使日常统计失真；部分支付宝文件把成功退款金额放在单独一列 | 这些记录默认不选，明确显示勾选后的收支方向；退款金额列参与核对，不自动冲减原支出 | 合成 CSV 与核心测试覆盖；退款净额计算未实现，不作该功能承诺 |
| 账务与导入 | 重复导出同一日期范围可能重复记账；仅按同日同额去重又会丢掉两笔真实消费 | 以平台和有效交易号识别同一笔，并检查原始信息；相同导入自动跳过，缺单号或手工近似项仅提示 | 覆盖原文件重导、重叠片段、相同金额不同单号、手工账目和缺单号记录 |
| 账务与导入 | 已经人工确认的转账再次导入仍被误归「需核对」；退款状态变化又不能当普通重复忽略 | 原始比对信息保留交易状态、交易类型和退款金额；完全一致的转账/退款重导可跳过，变化或旧状态缺失则阻断新增 | 核心回归覆盖确认后的转账与退款重导、退款发生后重导，以及旧比对信息兼容 |
| 账务与导入 | 同一文件中同号成功与退款/关闭记录可能互相掩盖；编辑账单后也可能丢去重身份 | 同号冲突使相关行全部转为不可选；编辑和存储往返仍保留导入来源、交易号与原始比对信息 | 核心测试覆盖状态冲突的不同排列顺序及编辑后重导；确认保存前还会重新校验 |
| 日常操作 | 历史账单导入后停在当前月份，用户可能以为没有成功；大量明细难以逐项核对 | 增加月份直达、导入后跳转、覆盖月份提示、30 行分页与筛选；默认仅选择普通完整交易 | 浏览器串联 21 组通过；原生文件导入与基础回归已完成 |
| 日常操作 | 取消识别或退出导入可能丢失原手工草稿；两个页签的草稿状态可能互相覆盖 | 取消和识别过程保留原草稿，替换前确认；统一两个页签的未保存状态，恢复原编辑器 | 浏览器取消与草稿回归通过；原生折叠草稿与确认回归通过 |
| 日常操作 | 从截图草稿切换到旧账目时，旧 OCR 状态可能残留并污染来源 | 放弃草稿后先清空截图状态，再装载旧账目；缺金额、日期或方向不能直接保存 | 核心缺项、原生确认门禁和普通编辑回归通过；另有独立源码审阅 |
| 日常操作 | 一次误导入难以回退；全账本回滚可能删掉后来手工记录 | 本会话保留最近一批新增 ID，撤销只删除这一批；提示其后编辑过的同批记录也会删除 | 精确按批次 ID 处理；不提供跨重启历史撤销 |
| 文件与平台 | 长交易号经数字转换会损坏；不完整、加密或异常压缩表格不应进入账本 | CSV 解码为字符串；XLSX 保留单元格文本，限制文件大小和展开规模，拒绝公式、加密文件、损坏数据与不安全引用 | XLSX 单元测试覆盖压缩、CRC、关系、日期、XML 和行列上限；CSV 300 笔、GBK、真实 DEFLATE XLSX 已通过原生专项实测；修复了 zlib 计数需 getZStream 获取的差异 |
| 文件与平台 | 把文字草稿测试误当图片 OCR 验收，会夸大实际可用性 | 原生系统 OCR 与浏览器本地 OCR 分别实现和验收；粘贴文字作为独立入口，任何识别结果都需人工核对 | 浏览器已识别一张清晰的合成中文单笔截图，非同源请求被阻止；原生 Core Vision 不支持模拟器，Mate X6 单张合成图片 OCR 与确认保存已通过 |

| 日常操作 | 输入法尚在展开时按返回，可能先触发丢弃草稿；只看键盘高度会漏掉该路径 | 综合输入框焦点与键盘状态，先清除输入焦点并收键盘；页面与底部面板使用相同规则 | 最终原生严格 Back 回归通过：键盘收起，无丢弃弹窗，文字保持不变 |
| 外屏布局 | 空账本装饰和留白挤压标题；下载的图片可能不在图库 | 外屏空态使用更紧凑尺寸，截图增加文件选择入口 | 最终模拟器外屏截图与入口检查；另已完成 Mate X6 系统图片 OCR 实测 |

## 数据与用户可见规则

- 每次最多 5,000 笔明细、文件不超过 8 MiB；超限明确拒绝，不静默截取前半份账单。
- 交易失败、关闭等记录跳过；同号冲突不能勾选直接新增。缺单号、同日同额等只提示疑似，确认是另一笔后可选。
- 退款与转账需要用户明确选择是否按显示方向计入；统计没有自动净额修正。
- 截图只生成草稿，原文保留供核对。缺字段留空，歧义不猜测，保存同日同额记录前再次提醒。
- 旧 v1 账本可读；导入后避免降级，旧版重存会丢失新身份字段。数据仍仅保存在本机，卸载或清除数据会删除账本。

## preview.2 外屏补丁

真机在导入后显示长提示与独立撤销按钮，挤压了账单列表。将二者合并为 48vp 行，外屏汇总改为紧凑尺寸，并缩减间距；展开时的汇总尺寸保留。最终 Mate X6 实测两条账单均完整可见，各高 212px；批次撤销后账本为空。该补丁仅修改原生布局及版本码，OCR/解析/存储逻辑保持不变。
